# Cookbook

Небольшой учебный репозиторий с текстовым рецептом. Простой пример хранения файлов и работы с Git; программного приложения здесь нет.

## Содержимое

- [Рецепт блинов](recept_blinov.txt) — ингредиенты и последовательность приготовления.

## Просмотр

Откройте файл по ссылке выше либо склонируйте репозиторий:

```bash
git clone https://github.com/AlfredNike/cookbook.git
cd cookbook
```

Зависимости, сборка и запуск не требуются. Основной проект разработки: [Code Grader](https://github.com/AlfredNike/getruncode).
